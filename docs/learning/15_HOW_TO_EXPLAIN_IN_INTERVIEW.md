# Interview explanation

**What:** Present the product as an AI shopping interface backed by deterministic commerce.

**Why:** The strongest story connects a visible interaction to a deliberate consistency or security decision.

**How / request flow:** Show discovery → comparison → product detail → real cart → coupon → checkout → order history. Then trace one request through the code and discuss one limitation.

**Key files:**

- `docs/portfolio/INTERVIEW_DEMO.md`
- `docs/portfolio/ARCHITECTURE.md`
- `docs/portfolio/AI_ARCHITECTURE.md`
- `docs/portfolio/TRADEOFFS.md`

**Interview talking points:** Opening: 'ShopSmart lets a shopper discover and compare products conversationally, while server services remain authoritative for pricing, inventory and orders.' Be explicit that products are fictional portfolio records and checkout has no real payments.
